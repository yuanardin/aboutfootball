# **App Name**: ScoreCast

## Core Features:

- News Aggregation: Fetch and aggregate football news from various sources.
- Match Results: Display recent match results with scores and details.
- Team Standings: Show current team standings for different leagues.
- AI News Summarizer: Use an AI tool to generate concise summaries of sports news articles.
- User Authentication: Allow users to register and log in via Email/Password or Social Login (GitHub/Google)

## Style Guidelines:

- Primary color: Neon Blue (#13D4FF) for an energetic and modern feel.
- Background color: Dark Blue (#1A202C) to provide a futuristic backdrop.
- Accent color: Cyan (#45F3FF) for highlights and interactive elements.
- Body and headline font: 'Space Grotesk' sans-serif, lending a tech-inspired aesthetic and high readability, and suitable for headlines or short chunks of text; longer text to use 'Inter'.
- Use sharp, minimalist icons with neon blue accents.
- Implement a glassmorphism effect on input fields for a sleek design.
- Subtle transitions and animations for a dynamic user experience.
